# Лабораторная работа №1

Численное интегрирование sin(x) на [0, π]: последовательная и параллельная реализации.

## Запуск в NetBeans после клонирования

1. Клонируйте репозиторий или распакуйте его архив.
2. В NetBeans выберите **File → Open Project (Файл → Открыть проект)** и укажите папку `laba1`, содержащую `build.xml` и `nbproject`. Не нужно создавать новый проект и копировать код.
3. Выберите проект **Lab1** и нажмите **Run Project (F6)**.
4. Результаты появятся в окне **Output (Вывод)**. Программа консольная, отдельного окна у неё нет.

Для компиляции нужен **JDK 8 или новее**, а не только JRE. В NetBeans должна быть включена поддержка Java и Ant (проект Java с существующим Ant-скриптом). Версия JDK, необходимая для самой IDE, зависит от версии NetBeans.

F6 запускает полный эксперимент: N = 10⁷, 10⁸, 10⁹; потоки 1, 2, 4, 8, 16, 32, 64; 2 прогрева и 5 измерений для каждой конфигурации. Он может занимать много времени. Для быстрой проверки укажите `--quick` в значении `run.args` в начале `build.xml`: N = 10⁶ и 10⁷, потоки 1, 2, 4, 8, 1 прогрев и 3 измерения. Цель `run-full` всегда запускает полный эксперимент.

## Запуск без NetBeans (включая Java 8)

Из папки репозитория:

```text
javac -encoding UTF-8 -d build/classes Lab1.java
java "-Dfile.encoding=UTF-8" -cp build/classes Lab1 --quick
```

Перед компиляцией создайте папку `build/classes` (в Windows: `mkdir build\classes`). Для полного эксперимента уберите `--quick`.

Если установлен Ant:

```text
ant run
ant run-full
ant -Drun.args="--n=1000000 --threads=1,2,4 --runs=3 --warmups=1" run
ant jar
java "-Dfile.encoding=UTF-8" -jar dist/Lab1.jar --quick
```

Команда `java Lab1.java` поддерживается только начиная с Java 11. На Java 8 используйте компиляцию через `javac`, как показано выше.
